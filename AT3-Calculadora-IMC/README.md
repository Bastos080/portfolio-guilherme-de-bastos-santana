# ⚖️ Calculadora IMC

## 📝 Descrição
Uma aplicação web simples para calcular o **Índice de Massa Corporal (IMC)**. O utilizador insere o peso e a altura nos campos correspondentes e clica em **Calcular** para obter o resultado.

---

## 🛠️ Tecnologias
- 💻 HTML5
- 🎨 CSS3
- ⚡ JavaScript
