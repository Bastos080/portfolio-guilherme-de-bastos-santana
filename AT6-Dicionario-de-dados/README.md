# Meu Dicionário 📚

Este repositório documenta e estrutura o projeto académico e prático **Meu Dicionário**, desenvolvido com foco na especificação de requisitos de software, modelagem de dados e implementação de uma interface web interativa.

---

## 🚀 O que foi feito neste projeto?

1. **Modelagem de Dados e Arquitetura:**
   * Desenvolvimento e estruturação de diagramas de arquitetura e base de dados, incluindo o **DER (Diagrama Entidade-Relacionamento)** armazenado na pasta `assets/`.

2. **Engenharia de Requisitos e Regras de Negócio:**
   * Análise detalhada e documentação formal baseada em cenários do mundo real (como o estudo de caso da **Kallan Calçados**), mapeando fluxos operacionais, requisitos funcionais e não funcionais na pasta `docs/`.

3. **Desenvolvimento Front-end:**
   * Implementação de uma interface web responsiva e funcional utilizando **HTML5**, **CSS3** e **JavaScript**, permitindo a navegação dinâmica e consulta de termos/dados.
